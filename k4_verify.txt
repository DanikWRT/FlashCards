K4 verification — priority algorithm (cards mode) — wt/k4
Date: run against vite dev server on port 5175

Overview
--------
Added a priority display order to the CARDS mode of /set/:id:
- Priority ON (default): card indices sorted ascending by per-card view count
  (getStats id), stable sort keeps ties in original index order => under-used
  cards shown first.
- Priority OFF: natural order [0,1,2,...].
- The pass order is computed ONCE on cards-mode entry and on "Заново" (restart),
  and stays FIXED for the whole pass (forward/back navigation does not change it).
- Toggle "Приоритет повторения" persists to localStorage key fc_priority_mode
  ('on'/'off'), default 'on'.
- Counter increment reused EXISTING recordCardView(id, originalIndex) untouched.
- Badge "Показов: N" near the card shows the current card's view count and
  updates on navigation.

Test data: set k4-test-set-0001, 7 cards. Seeded stats {0:5, 1:3, 2:1}, cards
3-6 have no counter (=0). Clean stable ascending order => [3,4,5,6,2,1,0].
