# Ресёрч функций Quizlet для импорта в FlashCards (2026-10-01, dsh-research)
# Источники: help.quizlet.com, quizlet.com/features/study-modes, блог Quizlet

## 1) Режимы изучения
- Flashcards: классический просмотр, клик/свайп переворот, стрелки/клавиши листают, Shuffle + автоплей.
- Знаю/еще учу (Star/Know/Still learning): ручная раскладка по стопкам, просмотр только нужной.
- Learn: адаптивный, вопросы разных типов, по мере ответов усложняет, spaced repetition + ML.
- Write: активное припоминание - термин показан, ответ печатаешь с клавиатуры.
- Spell: TTS озвучивает слово, печатаешь по буквам, проверка орфографии.
- Test: экзамен (заполнение пропусков/выбор/сопоставление/правда-ложь), результат в конце, настраиваемый.
- Match: гонка на время - сопоставить термины/определения, рекорды.
- Gravity (аркада) / Blast / Blocks: падающие термины/блоки, печатать ответ; Gravity упразднена.
- Quizlet Live: командная игра класса в реальном времени.
- Q-Chat (AI-тьютор): чат-тренажер по материалу (у Quizlet отключен с июня 2025).
- Practice Tests (AI): генерирует экзамен из набора/заметок.
- Study Guides: авто-конспект ключевых концепций.
- Study with friends: совместная сессия по ссылке/QR, общий результат/лидерборд.

## 2) Создание / импорт данных
- Ручное создание набора, Tab между полями.
- Импорт текстом (Word/Excel/Google Docs): вставка, настраиваемые разделители.
- Импорт/экспорт CSV: 2 столбца, без заголовков, UTF-8, для 50+ карточек.
- OCR с мобильного: сканирование распечаток/конспектов камерой.
- Magic Notes (AI): заметки -> мгновенные карточки/тесты/конспекты.
- AI Design / Auto-Define: AI генерирует примеры, определения, варианты ответов.
- Diagram sets: термин привязан к точке на изображении.
- Изображения: свои или галерея.
- Клонирование/переиспользование чужих наборов, объединение.
- Настройка языков, видимость (публичный/класс/пароль), форматирование текста.

## 3) Прогресс / повторение
- Spaced repetition: в Analysis Learn, повторение по усвояемости.
- Progress: группы. Not studied / Still learning / Mastered; синхронизация между устройствами.
- Memory Score: оценка усвоения, предсказание забывания, даты повторений.
- Answer Streaks: счетчик подряд правильных (с 5), сброс при ошибке.
- Smart Grading: AI оценивает письменный ответ по смыслу.
- High scores: рекорды в играх, конкуренция.
- Activity Center: журнал активности, годовой отчет.

## 4) Социальное / совместное
- Классы (код/ссылка/email, наборы класса).
- Папки. Публикация/шеринг (ссылка, email, QR, соцсети, Teams, embed).
- Лидерборды. Class Progress (для учителя).
- Поиск чужих наборов, Top Creator, подписка на авторов.

## 5) Интерфейс / UX
- Озвучка TTS (терминов/определений, скорость/голос), запись своего аудио.
- Автовоспроизведение (автопрокрутка). Shuffle (перемешивание).
- Шорткаты: стрелки листания, Tab между полями, полноэкранный режим.
- Звездочки (важные карточки). Изображения на карточках; свайпы; QR джойна.
- Аудио-лекции; офлайн (моб.); маскоты-геймификация.

- Быстрый выигрыш: импорт CSV/текста, озвучка, перемешивание, звездочки, шорткаты, автопрокрутка.
