# Правила генерации карточек FlashCards (для скилла формирования JSON)

При создании карточек придерживаться структуры JSON-набора:
`{ topic, lesson_meta, cards: [{ word, translation, examples:[{en,ru}], family?, phrases? }] }`

Порядок полей в карточке:
1. word - термин (англ.)
2. translation - перевод (рус.) + при необходимости пояснение в скобках
3. examples - 1-2 примера употребления {en, ru}
4. УСТОЙЧИВЫЕ ФРАЗЫ "phrases" (ДОБАВИТЬ, перед family): перечень распространённых устойчивых словосочетаний с переводом, напр.
   - "Do pull-ups on a bar - подтягиваться на перекладине"
   - "push-ups - отжимания"
5. family - родственные формы/однокоренные (словоформы)

ВАЖНО: устойчивые фразы (phrases) идут ПЕРЕД родственными формами (family).
Правило добавлено по просьбе пользователя (2026-10-01).
